# Overview
In this project, I explored **Graph Theory** and **Social Network Analysis (SNA)** using Python's `networkx` library and visualized the results interactively via a Streamlit dashboard.

## Key Concepts Learned
1. **Nodes and Edges:** In graph theory, entities are represented as **nodes** (e.g., individual members or users) and relationships are represented as **edges** (e.g., friendships or interactions).
2. **Degree Centrality:** This metric measures the number of direct connections a node has. Nodes with high degree centrality act as major hubs or key influencers within a network.
3. **Zachary's Karate Club Graph:** I utilized this classic benchmark social network dataset to map real-world faction splits and relationship dynamics.

## Tech Stack
* Python
* NetworkX (Graph analysis)
* Matplotlib (Data visualization)
* Streamlit (Interactive web UI)
