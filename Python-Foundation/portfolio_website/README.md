# Data Science Portfolio Prototype

A Streamlit portfolio-style landing page showcasing example machine-learning and data-science projects. The current page is a local prototype; its project buttons and contact links are placeholders.

## Run locally

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

Before deployment, replace the placeholder project actions and contact links with working destinations.
